# 期货结算分析

自动处理中国期货市场监控中心/示例期货每日结算单（.xls），长期存档、跟踪、分析盈亏与风险。**软件与数据完全分离**：程序本体不包含任何数据，所有数据以明文 JSON 保存在你自己指定的「数据目录」中（格式见 `docs/数据格式.md`），可自由备份、迁移、用其他工具读取。数据不出本机，无任何网络上传。

## 快速开始（Mac）

```bash
cd futures-ledger
npm install
npm start
```

也可以直接双击 `启动.command`（首次需在右键菜单中选「打开」）。

## Windows 使用

在 Windows 上安装 Node.js (https://nodejs.org) 后：

```bash
cd futures-ledger
npm install
npm start
```

打包成安装包（在 Windows 上执行）：`npm run dist:win`。
Mac 打包：`npm run dist`（若 Electron 下载卡住，用 `ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/ npm run dist`）。

## 日常使用

1. 每天从监控中心下载当日结算单 `.xls`（或配置监控目录，下载即自动导入）
2. 打开应用 → 点「导入结算单」，或**直接把文件拖进窗口**（可多选/多天）
3. 已存在的交易日自动跳过；勾选「覆盖已有同日」可重新导入修正账单

## 功能

- **仪表盘**：人话横幅（今天赚了 X 元，含完整算式）＋客户权益/净值/风险度配色/手续费占比；净值曲线、风险度曲线、品种累计盈亏拆分、每日成交手数；当前持仓；口径说明
- **交易统计**：胜率、平均盈利/亏损、盈亏比、日胜率、连续盈亏天数、单日最大盈亏、最大回撤、日内 vs 隔夜拆分、手续费拆分（开仓/平仓-日内/平仓-隔夜）、品种级统计
- **汇总**：按日/按月自由切换，盈亏、权益、保证金、风险度、链式验算状态；月度模式可打印留档（A4 优化）与导出 Excel/CSV
- **历史持仓**：回看历史上任一交易日收盘时的持仓快照
- **明细**：成交明细 / 平仓明细分段切换，多维筛选，导出 CSV
- **品种统计**：手数、成交额、手续费、盈亏、胜率
- **多账户**：顶栏切换账户，统计口径随账户隔离
- **数据管理**：数据健康面板（验算异常/校验异常/目录大小/最近导入）、数据目录切换、监控目录、外部备份目录、配置、备份与恢复、回收站

## 数据可靠性设计

- **链式验算**：每日导入自动核对 上日结存+出入金+平仓盈亏+浮动盈亏−手续费 = 客户权益
- **文件校验和**：每个结算单 JSON 带 SHA-256，被误改/损坏立即发现
- **原子写入 + 索引自愈**：写入不留半截文件；索引损坏自动扫描目录重建
- **自动备份**：每次导入/删除后自动生成备份（滚动保留 10 份）；可配外部备份目录自动同步
- **导出完整备份 / 从备份恢复**：一键打包全部数据（含原始 xls）
- **回收站**：删除的结算单可恢复、可清空
- **文件名日期校验**：文件名与内容日期不一致会拦截
- **导入中断恢复**：导入中断的日期在索引重建时自动补录

## 口径说明

- 全工具盈亏统一用**逐笔对冲**口径，与结算单主表"平仓盈亏"可能存在小额尾差（结算口径调整项），以工具验算为准
- **客户权益 = 当日结存 + 浮动盈亏**，权益唯一标准是客户权益
- 浮动盈亏按今结算价 vs 开仓成本计算；结算价 = 全天成交量加权平均价，≠收盘价

## 数据目录结构（数据层）

```
期货结算数据/
├── config.json                          # 初始入金、监控目录、外部备份目录
├── index.json                           # 已导入清单（含校验和）
├── statements/123456789_2026-09-21.json # 每天的规范化结算数据（含 dataVersion）
├── raw/                                 # 原始 .xls 归档
├── backups/                             # 自动备份（滚动保留 10 份）
├── .trash/                              # 回收站
└── logs/app.log                         # 运行日志
```

备份 = 复制整个数据目录，或用界面里的「导出完整备份」。换电脑 = 拷贝数据目录 + 在新机器上指定同一目录。

## 项目结构

```
futures-ledger/
├── src/
│   ├── main.js        # Electron 主进程：窗口、IPC、监控目录、命令行导入、日志
│   ├── preload.js     # 渲染进程桥接（contextBridge）
│   ├── parser.js      # 结算单 .xls 解析器（标签定位 + 归一化表头匹配 + 链式验算）
│   └── store.js       # 数据层：JSON 存储、原子写、索引自愈、回收站、备份、汇总计算
├── renderer/
│   ├── index.html     # 界面结构
│   ├── app.js         # 界面逻辑与图表（看门狗保证缩放正确）
│   ├── style.css      # 样式（含打印视图）
│   └── vendor/        # ECharts（本地打包，不依赖外网）
├── test/
│   ├── fixtures/      # 脱敏金样本结算单（用于回归测试）
│   ├── verify.js      # 解析回归测试
│   ├── acceptance.js  # 验收标准测试
│   └── store.test.js  # 数据层单元测试
├── docs/
│   ├── 数据格式.md     # 数据目录每个文件的格式说明书
│   └── 需求要点.md     # 原始需求文档
└── 启动.command        # Mac 双击启动脚本
```

## 技术说明

- Electron + 原生 HTML/JS（无前端构建），图表 ECharts 本地打包；解析 SheetJS(xlsx)
- `src/parser.js` 解析结算单（标签定位 + 归一化表头匹配）；`src/store.js` 存储、备份、回收站与汇总
- 当前适配示例期货/监控中心标准《客户交易结算日报(逐笔对冲)》，表头匹配已做归一化兼容；换期货公司格式如需支持，提供样本即可扩展
- 期权/证券交易记录目前仅解析留存、未纳入统计，界面会明确提示
- 测试：`npm test`（解析回归 + 验收标准 + 数据层单元测试，使用脱敏金样本 `test/fixtures/`）
- 详细数据格式：`docs/数据格式.md`
