# 数据格式说明书

本文档描述「期货结算分析」数据目录中每个文件的格式与含义。所有数据均为明文 UTF-8 JSON，可用任何文本编辑器或程序直接读取。设计目标：**十年后、换任何工具、不依赖本软件，也能完整理解和重建你的交易档案**。

## 目录结构

```
期货结算数据/
├── config.json                  # 用户配置
├── index.json                   # 已导入清单（含每个文件的校验和）
├── statements/<账号>_<交易日>.json   # 核心：每日规范化结算数据
├── raw/<账号>_<交易日>__<原文件名>.xls   # 原始结算单归档（永不变动）
├── backups/<时间戳>__<原因>/     # 自动备份（statements + index + config，滚动保留 10 份）
├── .trash/                      # 回收站（被删除的结算数据，可恢复）
└── logs/app.log                 # 运行日志
```

## config.json

| 字段 | 类型 | 含义 |
|---|---|---|
| initialDeposit | number | 工具启用前的累计净入金（元）。净值 = 客户权益 − 累计净入金 |
| monitorDir | string | 监控目录路径，留空不启用。该目录出现新 .xls 会自动导入 |
| backupDir | string | 外部备份目录路径，留空不启用。每次导入后自动同步复制解析数据 |

### 关键口径（务必理解）

- **链式验算**：`上日结存 + 当日存取 + 平仓盈亏 + 浮动盈亏 − 手续费 + 权利金 = 客户权益`，每日导入自动核对，`chainOk=false` 表示该日数据异常
- **权益 = 当日结存 + 浮动盈亏**（`equityOk` 校验）
- **浮动盈亏**按今结算价 vs 开仓成本计算；结算价 = 全天成交量加权平均价，≠ 收盘价
- 所有金额单位：人民币元；`riskRatio` 为小数（0.3041 = 30.41%）

## dataVersion 迁移承诺

- 当前版本为 **1**
- 任何未来的结构变更都会递增版本号，并提供自动迁移：新版本读取旧文件时自动升级为新结构，**你的原始文件永不被改写**
- 原始 `.xls` 归档（`raw/`）永不变动，是最终的兜底依据
