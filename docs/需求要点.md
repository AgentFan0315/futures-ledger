# 期货结算单长期记录工具 —— 需求要点（交给开发 AI 的完整提示）

## 0. 项目背景

用户是期货新手（示例期货账户），每天从中国期货市场监控中心（www.cfmmc.com）下载当日结算单（.xls），需要本机工具长期存档、跟踪、分析。核心痛点：看不懂结算单、不知道每天赚亏、风险度飙升无感知、品种盈亏混在一起、手续费侵蚀利润无统计。

## 1. 数据源与导入

- 文件格式：监控中心标准结算单 `.xls`（老格式），文件名规律 `账号_YYYY-MM-DD.xls`，如 `123456789_2026-09-22.xls`
- 每个文件含多个 sheet：`客户交易结算日报`、`品种汇总`、`成交明细`、`平仓明细`、`持仓明细`、`期权成交明细`、`期权品种汇总`、`期权类型汇总`、`证券成交明细`、`证券买卖汇总`
- 解析注意：
  - `客户交易结算日报` 是**竖排"字段名-数值"键值对**，且夹杂合并单元格、大量 NaN 空列、以及超长的公告文本列（单元格字符数 >60 的一律视为公告文本过滤掉）
  - 数值可能带千分位逗号，需清洗
  - 导入后做**链式验算**：`上日结存 + 平仓盈亏 + 浮动盈亏 − 手续费 + 出入金 = 客户权益`，不相等则标记"该日数据异常"（正常也应相等；不等说明解析错误或结算单口径调整）
  - 支持批量导入历史文件 + 每日增量导入；自动检测日期断链（缺哪天就提醒）

## 2. 每日必须入库的核心字段

### 资金状况（来自"客户交易结算日报"）
上日结存、当日存取合计、平仓盈亏、浮动盈亏、当日手续费、当日结存、客户权益、保证金占用、可用资金、风险度、实有货币资金

### 持仓明细（来自"持仓明细"sheet，逐笔）
合约、方向（买/卖）、手数、开仓价（逐笔）、昨结算价、今结算价、浮动盈亏、交易保证金、投机/套保标志、实际成交日期

### 品种汇总（来自"品种汇总"sheet）
逐品种：成交手数、平仓盈亏、手续费

### 成交/平仓明细（来自"成交明细""平仓明细"）
逐笔留存，供胜率、盈亏比、日内/隔夜行为统计

## 3. 口径统一（最重要的设计约束）

结算单自身混用两种口径，工具必须统一并向用户写明：

1. **全工具盈亏统一用"逐笔对冲"口径**（开仓价 → 平仓价），并在界面显著位置写明：与结算单主表"平仓盈亏"可能存在小额尾差（结算口径调整项，正常），以工具验算为准
2. **权益的唯一标准是"客户权益"**，不是"当日结存"。界面必须同时显示两者并注明：`客户权益 = 当日结存 + 浮动盈亏`
3. 每日输出口径说明固定一句话："浮动盈亏按今结算价 vs 你的开仓成本计算；结算价=全天成交量加权平均价，≠收盘价"

## 4. 核心功能

### 4.1 每日一页 Dashboard（人话翻译）
- 当日盈亏（平仓 + 浮动 − 手续费，一句话："今天赚了 X 元"）
- 当前客户权益 / 累计净盈亏（权益 − 累计入金）
- **当前风险度 + 颜色预警**：<50% 绿，50–80% 黄，>80% 红，>95% 红闪
- 当前持仓清单（含每手成本、浮盈、距交割月天数）
- 当日手续费、当月累计手续费、**手续费占累计盈利比例**

### 4.2 长期曲线
- 净值曲线（客户权益 − 累计入金，按日）
- 风险度曲线（按日）
- 品种盈亏累计拆分（例：黄金累计 −1,940，白银累计 +3,970）
- 每日成交手数柱状图（交易频率自检）
- 最大回撤（从净值曲线计算）

### 4.3 交易行为统计
- 平仓明细计算：胜率、平均盈利、平均亏损、盈亏比
- 日内（今开今平）vs 隔夜持仓的盈亏拆分
- 单日最大亏损、单日最大盈利

## 5. 期货特色预警（规则驱动）

1. **交割月限制预警**：维护各交易所个人客户最后持仓日规则表（至少覆盖：上期所/能源中心个人不得进入交割月，最迟持有到交割月前一月最后一个交易日；大商所、郑商所、广期所同类规则；中金所股指为现金交割、个人可持有至最后交易日但需注意）。
   对持仓合约计算"距离个人最后交易日"天数，≤10 天每日提醒，≤3 天强提醒。合约月份编码解析：如 AU2611 = 2026 年 11 月交割月。
2. **长假提保提醒**：解析每日结算单公告栏文本，提取"自 X 月 X 日结算时起调整保证金/涨跌停板"类公告，单独置顶显示，并提醒"保证金占用将增加，关注可用资金"。
3. **保证金比例突变检测**：同一合约相邻两日"保证金占用 ÷（今结算价 × 手数 × 单位）"变化超过 5 个百分点时提醒（识别交易所提保动作）。
4. **期权到期提醒**：公告文本中如出现 ETF 期权/期货期权到期日，提取并提醒。
5. **风险度日环比跳升**：风险度单日上升超过 20 个百分点时主动提醒（例：30%→90% 这种情况必须弹出来）。

## 6. 技术建议

- **推荐技术栈：Python**（pandas + xlrd 读 .xls，SQLite 本地存储，matplotlib/或轻量 GUI 如 PySide）。理由：.xls 解析、键值对清洗、统计分析在 C 语言里成本极高
- 若用户坚持 C：需引入 libxls 解析 .xls，SQLite 存库，功能裁剪为"只读资金状况主表"，成交明细等复杂 sheet 放弃
- 替代方案：用户每天把结算单另存为 .csv 后导入，可大幅简化解析
- 数据不出本机：结算单含账号、姓名等敏感信息，不做任何网络上传，不集成第三方云服务
- 配置文件：本金、预警阈值、监控中心账号（仅本地存储，脱敏显示）

## 7. 验收标准（按此验收）

1. 导入 09-21、09-22 两天结算单后，工具显示的每日客户权益与结算单原文分毫不差
2. 能自动算出：黄金累计亏损约 1,940 元、白银累计盈利约 3,970 元（与人工核算一致）
3. 风险度曲线能显示 30.41% → 90.47% 的跳升
4. AU2611 持仓会触发"个人客户最迟 2026-10-30 前平仓"的提醒
5. 09-22 结算单的提保公告能被提取并置顶
